# 데이터 책임 및 라이선스 고지 (초안)

> ⚠️ **법적 고지**: 이 문서는 **약관 초안(템플릿)** 이며 법률 자문이 아니다. 실제 서비스
> 적용 전 반드시 **변호사 검토**를 받아야 한다. 관할(한국 PIPA / EU GDPR 등)에 따라
> 추가·수정이 필요하다. CLAUDE.md §14 Privacy 5원칙의 구체화.

LinkMind 의 운영 모델(2026-06-03 확정)과 그에 따른 데이터 책임 소재를 명시한다.

---

## 1. 운영 모델 — space(조직)가 단일 단위

- **1 조직 = 1 space**. 조직의 멤버 전원이 같은 데이터(자료·위키)를 공유한다.
- space 는 **격리·학습·책임의 단일 단위**다:
  - **격리**: 다른 조직(space)의 데이터는 RLS + 앱 필터 + 벡터 필터로 절대 접근 불가.
  - **학습**: 그 조직의 데이터로 **그 조직의 모델만** 학습한다 (cross-space 학습 금지).
  - **책임**: 그 조직이 수집·학습한 데이터의 적법성에 대한 책임은 **그 조직**에 있다.
- 멤버 계정은 **조직의 루트 관리자가 발급**한다 (self-signup 없음).

## 2. 데이터(콘텐츠) 책임 — 조직에 귀속

1. **수집 적법성**: 조직 멤버가 LinkMind 에 수집(ingest)하는 모든 자료 — URL/링크,
   업로드 파일, 메신저 가져오기 등 — 는 멤버가 **합법적으로 접근·이용 권한을 가진**
   자료여야 한다. 저작권·라이선스·기밀 위반 자료의 수집 책임은 **수집한 멤버와 그가
   속한 조직**에 있다.
2. **조직 데이터의 통합 사용**: 같은 조직(space) 안에서는 멤버 간 데이터가 공유되며,
   조직 차원의 분석·학습에 함께 사용된다. 한 멤버가 부적절한 라이선스의 자료를
   수집했다면, 그로 인한 책임은 **조직이 진다** (조직 내부의 사용 규칙·승인은 조직의
   몫이다).
3. **운영자(설치/호스팅 제공자) 면책**: LinkMind 인스턴스를 설치·호스팅하는 운영자
   또는 소프트웨어 제공자는 **인프라만 제공**하며, 각 조직 space 의 데이터 내용·적법성·
   학습 결과에 대해 책임지지 않는다. 운영자는 RLS 격리로 인해 조직 데이터에 **접근하지
   않으며**, 사용자 데이터로 운영자 자신의 공통 모델을 학습하지 않는다 (§14 #1).

## 3. 학습 데이터 사용

- 조직이 수집한 데이터는 **그 조직의 개인화 모델(LoRA 등) 학습**에 사용될 수 있다.
- per-item "학습 사용 여부" 선택 기능은 **현재 제공하지 않는다** (보류). 즉 조직 데이터는
  기본적으로 조직 모델 학습 대상이며, 부적합 자료의 배제는 조직의 수집·관리 책임이다.
  (향후 필요 시 `items.use_for_training` 플래그로 가볍게 도입 가능 — 현재 미구현.)
- **cross-organization 학습 절대 금지**: 한 조직의 데이터가 다른 조직/운영자의 모델
  학습에 쓰이는 일은 없다 (§14 #1, #2).

## 4. 삭제 권리 (GDPR / 한국 PIPA)

- 조직 또는 멤버의 삭제 요청 시, 해당 데이터를 Postgres + Qdrant + 객체 스토리지에서
  영구 삭제한다. 학습 결과(모델)에 반영된 경우의 처리 범위는 별도 정책으로 정한다.
